🔧 Servo Angle Tuner (22ch)

開啟後才顯示 22ch 微調器（長按 ±1 連發，offset 即時計算，已禁用長按選單）

獨立於舵機分頁的進階微調器 — 直接修改 22 顆 servo 角度，±1° 精調，一鍵讀取全部目前角度。與原廠 1.0.0.4 校準工具相同佈局（1-20 對應肩/肘/髖/膝/踝/手/頭，21-22 為擴展）。長按 ±1 連發時已禁用系統複製選單。

🔢 更改舵機 ID

啟用後才會顯示更改舵機 ID 功能

透過胸板命令 10 [舊 ID][新 ID]，經舵機碼 205 寫入舵機 EEPROM，掉電保持。同一總線不可有兩顆相同 ID；完成後請至舵機頁面試動新 ID 驗證。

⚠️ 胸板左右兩個舵機接口不可混插：1,2,3,7,8,9,10,11,17,19,20,21 僅可連接右側接口；4,5,6,12,13,14,15,16,18,22 僅可連接左側接口——接錯一側將無法識別。若新 ID 與舊 ID 分屬不同側，更改後須先拔線改插，否則將立即失去連接！只能在斷電情況下接駁舵機，通電後不可插拔，否則會燒板！
