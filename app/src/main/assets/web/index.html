🔧 Servo Angle Tuner (22ch)

Turn on to show 22ch tuner (long-press ±1 repeats, offset live, copy menu disabled)

Standalone tuner — tune 22 servos directly, ±1° fine-tune, one-click read. Matches factory 1.0.0.4 layout (1-20: shoulder/elbow/hip/knee/ankle/hand/head, 21-22 extra). Long-press ±1 repeats, copy menu disabled.

🔢 Change Servo ID

Turn on to show the servo ID changer

Chest cmd 10 [old ID][new ID], written to servo EEPROM via servo code 205, persists across power cycles. No two servos on the same bus may share an ID; verify by moving the new ID in the Servo tab afterwards.

⚠️ The chest left/right servo ports are not interchangeable: IDs 1,2,3,7,8,9,10,11,17,19,20,21 must use the right port; IDs 4,5,6,12,13,14,15,16,18,22 must use the left port — the wrong side is not recognised. If the new ID is on the other side, move the plug after the change or contact is lost immediately! Only connect or disconnect servos while powered off — never plug or unplug while powered on, or the board will burn!

🔌 Servo Firmware

Turn on to show servo firmware

Reads each servo firmware version via chest command 14, read-only. The version format is not fully verified — for reference only. Reading all takes ~10+ seconds.

🔥 Servo Firmware Upgrade

Dangerous — may brick the servo. Flow: upload an exactly-7168-byte bootloader-free image → confirm twice → flash 112 pages via chest cmds 16/17 → wait for uplink 134. Do not power off or touch the robot while flashing.
